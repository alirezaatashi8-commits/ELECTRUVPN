# V9.2 — Free Trial, Config Delivery, Targeted Broadcast

## Free trial (user bot: 🎁 تست رایگان)
Panel → Shop → set MB, hours, Inbound ID, enable.
One trial per Telegram ID. Auto-disable after time/MB (worker every 30m).

## Config delivery (📁 دریافت کانفیگ)
Sends:
- sing-box style JSON document
- subscription.txt with share link
- QR Code PNG of the share link

## Targeted broadcast
Targets: all | expiring_today | expiring_3d | high_usage (≥10GB) | inactive | trial
