# V9.7 — Cloud Backup & Account Migration (ربات + مینی‌اپ + ادمین)

## هدف
کاربر با یک کلیک از ربات یا مینی‌اپ، کانفیگ‌ها / ساب‌ها / خلاصه سفارش / موجودی کیف پول را به‌صورت ابری ذخیره می‌کند و بعد از تعویض گوشی یا ریست تلگرام با یک **کد بازیابی** دوباره همه را به حساب جدید وصل می‌کند — بدون تیکت به پشتیبانی.

اگر کاربر کد را گم کرد / ناقص زد / منقضی شد، **ادمین** می‌تواند کد را پیدا کند، کد جدید صادر کند، یا کد را دوباره فعال و برای کاربر بفرستد.

## منوی ربات کاربر
- ☁️ **پشتیبان ابری** — ساخت/چرخش کد (`EV-XXXX-XXXXXX`)
- ♻️ **بازیابی اکانت** — ورود کد و لینک‌کردن مجدد
- 🚫 **باطل کردن کد** — غیرفعال‌سازی دستی کد فعلی

## مینی‌اپ (TMA)
تب **پشتیبان** + APIهای `/api/tma/backup/*`

## ابزار ادمین (ربات ادمین)
| دستور | کار |
|--------|-----|
| `/backupcode آیدی_یا_ایمیل` | نمایش همه کدهای کاربر (کامل) + وضعیت فعلی اکانت |
| `/issuebackup آیدی` | صدور کد جدید برای کاربر (حتی اگر خودش نتواند) |
| `/sendbackup آیدی` | ارسال کد فعال به چت تلگرام کاربر |
| `/reenablebackup کد` | فعال‌سازی مجدد کد منقضی/قفل‌شده (+۳۰ روز) |
| `/find …` | جستجو + نمایش خلاصه کدهای پشتیبان |

نقش‌های مجاز: owner / admin (همه) · support (فقط backupcode و sendbackup)

## امنیت
- انقضای پیش‌فرض ۳۰ روز
- حداکثر ۵ تلاش ناموفق → قفل
- نرمال‌سازی کد (با/بدون خط تیره، حروف کوچک/بزرگ)
- چند کلاینت برای یک تلگرام: ایندکس یکتا `(telegram_user_id, client_id)`
- بازیابی فقط کلاینت‌های موجود در DB را لینک می‌کند

## باگ‌فیکس‌های این نسخه
- نرمال‌سازی ورودی کد (بدون خط تیره / فاصله / حروف کوچک)
- قفل پس از تلاش ناموفق روی کدهای غیرفعال هم
- بازیابی چندکلاینتی بدون خطای unique روی `telegram_user_id`
- خطای واضح وقتی همه کلاینت‌های اسنپ‌شات از DB حذف شده‌اند
- ادمین می‌تواند کد گم‌شده را پیدا/صادر/ارسال کند
