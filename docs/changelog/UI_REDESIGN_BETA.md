# ELECTRUVPN BETA — Red Premium UI

This build applies the new dark/red product visual language across the existing panel without changing API behavior or operational flows.

## Visual system
- Dark charcoal / near-black surfaces
- ElectruVPN red as the primary action and navigation accent
- Green / amber / red reserved for runtime status semantics
- Red glow used selectively for active navigation, focus, important actions and charts
- Consistent rounded surfaces, borders, shadows and dense data layouts
- Responsive mobile navigation retained
- Login screen, dashboard, tables, forms, settings, modals, drawers, command palette and notifications share the same visual system

## Functional safety
This redesign is CSS/brand/visual-layer focused. Existing backend routes, Alpine state, permissions and operational APIs are preserved.
